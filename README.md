 Every big journey starts with a small step, and today mine began with the very first SQL command — SELECT.

Today’s focus: getting comfortable with the SELECT and DISTINCT statements — the tools that let us peek into the data and discover something new every time.

💡 What I explored today:
 • Viewing tables with SELECT
 • Filtering and choosing specific columns
 • Checking how data is structured
 • Using DISTINCT to find unique entries

🎯 Challenge:
 List all unique hospital services available in the hospital.
⚙️ Query I wrote:

SELECT DISTINCT service as hospital_services
FROM patients;

🧠 Reflection:

 Even the simplest SQL lines can reveal meaningful patterns.
 Data speaks — you just need to know how to ask the right question.
